# Scala

[Scala](http://www.huygens-fokker.org/scala/) is the long-established free tool for designing and analyzing musical scales and tunings, maintained by the Huygens-Fokker Foundation. It has a vast built-in scale archive and a deep command set for working with just intonation, EDOs, and temperaments — the natural companion to a Sagittal workflow, since it is where many microtonalists build the tunings they then notate.

Scala includes support for Sagittal symbols.

{% hint style="info" %}
Scala is a tuning tool, not a score editor. For putting sagittals onto a staff, see the [notation software guide](notation-software.md).
{% endhint %}
