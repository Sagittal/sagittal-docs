# The Sagittal Calculator

The **Standard JI Notation Calculator** is a downloadable spreadsheet that does the [JI notation](../notation-how-to-guides/just-intonation.md) work for you. You give it a pitch; it hands back the Sagittal notation — rendered in real Bravura Text glyphs, not ASCII approximations.

## What it does

Enter your pitch as a **ratio** or a **prime exponent vector**, and the calculator returns its notation in both the [Evo and Revo](../concept-explanations/evo-v.-revo.md) flavors, at each [precision level](../notation-how-to-guides/just-intonation.md) (Medium, High, Ultra, Extreme). Depending on how the underlying chain of Pythagorean fifths lines up with your pitch, it usually offers two options — sometimes three.

{% hint style="info" %}
A symbol keeps the **same default value at every precision level** — `/|` is always 81/80 — so the same pitch is notated consistently no matter which level you read off.
{% endhint %}

## Using it well

Two things to keep in mind:

* **One pitch at a time.** The calculator treats each pitch in isolation, so it is up to you to avoid **nominal crossing** across a passage — make sure none of your C's end up higher than your D's, and so on.
* **No arbitrary cents.** You enter exact JI ratios, not free-floating cent values. (This was a deliberate choice: a JI notation that accepted arbitrary cents might not look like a JI notation to the purists. Cent input is reserved for the planned web app.)

## Where it comes from

The spreadsheet is Douglas's modernization of George Secor's final JI Notation spreadsheet — the same carefully settled capture-zone boundaries, now showing the actual font glyphs. It answered a request the community had been sitting on for four years. It is offered as a downloadable `.xlsx` (and `.ods`) from [sagittal.org](https://sagittal.org).

One day there will be a true web app that supports *every* Sagittal notation. For now, this spreadsheet gets you exactly what you need for JI.

{% hint style="info" %}
To see the glyphs, you will need the Bravura Text font installed.
{% endhint %}
