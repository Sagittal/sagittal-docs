# StaffCode

This page will cover [staffcode.org](https://staffcode.org), which renders inline Sagittal and conventional staff notation from compact text (e.g. `Ab\!`) using BravuraTextSC — its niche being transparent, copy-pasteable notation for the forum and wiki, not a notation-software replacement. (Sources: StaffCode and font email digests.)
