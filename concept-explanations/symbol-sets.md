# Symbol Sets

There are over a hundred Sagittal symbols. That number scares newcomers, so let us defuse it right away: the symbols are organized into a series of nested **symbol sets**, and you only ever learn as far up the series as your music requires.

{% hint style="info" %}
If Sagittal is a language, the set of all valid symbols is its dictionary — and just as with English, **no one knows the whole dictionary**. The simplest, most important words carry you astonishingly far. The sets are not levels in a video game to be beaten; they are convenient **stopping points** where you get to say "that's enough."
{% endhint %}

## The nested series

Each set contains all the ones before it and adds more resolution. Their names climb a tongue-in-cheek ladder from the austere to the ridiculous:

| Set | Character | Adds | Resolution |
|---|---|---|---|
| **Spartan** | austere | the 8 core single-shaft pairs | 13-EDA |
| **Athenian** | luxurious | up to 13 pairs | 21-EDA |
| **Promethean** | adventurous | ~20 more symbols | 47-EDA |
| **Herculean** | almost godlike | the first accents | finer still |
| **Olympian** | godlike | mina accents | 233 minas / apotome |
| **Magrathean** | ridiculously precise | tina accents | 809 tinas / apotome |

"EDA" means **equal divisions of the apotome**: each set resolves the apotome into that many equal steps. Spartan's 13-EDA is already enough for the most popular EDOs and an extensive JI lattice.

{% hint style="info" %}
The Spartan set covers roughly **90% of what most people ever want.** The symbols in it appear in every other set. So learn Spartan and you have a real, working notation in hand — everything above it is there for when you specifically need more.
{% endhint %}

The Magrathean name is the giveaway joke: in *The Hitchhiker's Guide to the Galaxy*, the Magratheans are god-like planet-builders, and the one you meet is a bumbling old man. George and Dave thought any precision past Olympian was frankly farcical — that people only *believed* they needed it.

## Trojan sits askew

One set does not nest with the rest: **Trojan**, the set for the [12-Relative notation](../notation-how-to-guides/12-relative-trojan.md). Because it is fitted to 12-EDO's grid rather than to JI, it is drawn from an odd mix — some Spartans, some Athenians, plus three new pairs — and *skips* some Spartans while reaching as high as some Prometheans. If all you want is 12-Relative notation, this is the set you learn.

There is also a **Stoic** set in development (from the [Sagispeak](sagispeak.md) work): an alternative to Athenian built around right-side scroll flags. <!-- GAP: the Stoic set is not yet finalized; several of its Sagispeak spellings were still open as of the f=9 thread. -->

## Cores versus accents

The inner four sets — Spartan, Athenian, Trojan, Promethean — consist only of **cores**: symbols with at least one shaft and one flag, the sagittals you have been meeting all along. The three sets beyond them (Herculean, Olympian, Magrathean) introduce no new cores at all; what they add are **[accents](accents.md)** — small diacritics for sub-cent precision.

## What floats outside

Drawn *outside* the whole nested picture are the **compatible accidentals** — conventional sharps and flats (used in the [Evo flavor](evo-v.-revo.md)), quarter-tone and sesqui accidentals, the Stein–Zimmermann marks, and a handful of others. They are not Sagittal symbols, but they stand in for sagittals in certain notations.

{% page-ref page="sagittal-compatible-symbols.md" %}
