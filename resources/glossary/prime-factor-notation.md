# Prime Factor notation

A [just intonation](../../notation-how-to-guides/just-intonation.md) notation using one sagittal per prime factor of a ratio. Easy to learn and close to HEJI/Johnston, but a single note may carry several opposing sagittals — which motivates Sagittal's preferred [JI notation](../../notation-how-to-guides/just-intonation.md).
