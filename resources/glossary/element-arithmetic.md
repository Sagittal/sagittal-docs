# element arithmetic

For every flag or accent there is a sagittal consisting of a single shaft plus that element. Element arithmetic combines those elements' [primary commas](primary-comma.md) (in tempered form, if relevant) to give a sagittal's [sum-of-elements](sum-of-elements.md) value. [Flag arithmetic](../../concept-explanations/flag-arithmetic.md) is the special case using only flags.
