# sagitype

The scheme for typing sagittals in ASCII, mapping each element to a keyboard character (`/` `\` barbs, `(` `)` `~` curved flags, `|` up-shaft, `!` down-shaft, accents by quote marks). See [Sagitype](../../concept-explanations/sagitype.md).
