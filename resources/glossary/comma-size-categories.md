# comma size categories

The seven categories, by size only, from smallest to largest: [schismina](schismina.md), [schisma](schisma.md), [kleisma](kleisma.md), [comma](comma.md), small [diesis](diesis.md), medium diesis, and large diesis. Each boundary is the square root of a meaningful 3-limit comma.
