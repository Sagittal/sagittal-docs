# symbol set

Sagittal's symbols are organized into seven nested sets of increasing [precision](precision-level.md): [Spartan](spartan-symbol-set.md), [Athenian](athenian.md), [Promethean](promethean.md), [Herculean](herculean.md), [Olympian](olympian.md), [Magrathean](magrathean.md), plus the askew [Trojan](trojan.md) set for [12-Relative](../../notation-how-to-guides/12-relative-trojan.md) notation. See [Symbol Sets](../../concept-explanations/symbol-sets.md).
