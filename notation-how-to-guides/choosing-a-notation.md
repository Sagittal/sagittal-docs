# Choosing a Notation

This page helps you pick which kind of Sagittal notation you need before you dive into a how-to guide in the **Standard Notations** section.

{% hint style="info" %}
The pages in this unit do **not** strongly depend on each other. If you are only interested in one type of tuning, you can skip straight to the relevant guide and come back for the others later.
{% endhint %}

## The four families

There are four different types of Sagittal notation.

### EDO notations

For any **equal division of the octave**. EDOs are in a way the easiest tunings to notate, because an *n*-EDO has exactly *n* pitches to worry about — no more, no less. If you know your tuning as "22-EDO" or "31-EDO," this is your starting point.

{% page-ref page="equal-divisions-of-the-octave.md" %}

The central artifact here is the **Periodic Table of EDOs**, which gives a recommended standard notation for every EDO up to 72 (and the principles extend forever upward).

{% page-ref page="../concept-explanations/the-periodic-table-of-edos.md" %}

### Prime Factor notation

The first of Sagittal's two **just intonation** notations. Prime Factor is easy to understand — you use one sagittal per prime factor — and it most closely resembles other popular microtonal notations such as HEJI and Johnston. It has some important drawbacks (a single note can end up with several sagittals pulling in opposite directions), which is exactly what motivates the second JI notation.

{% page-ref page="prime-factor.md" %}

### JI notation

Sagittal's **preferred** just intonation notation — so it gets the simpler name, "JI notation." It uses one accidental per note, with no opposing alterations, and it is where Sagittal's **precision levels** come into play (see below).

{% page-ref page="just-intonation.md" %}

### 12-Relative notation

An option for anyone — notating an EDO, a JI tuning, or anything else — who wants to treat conventional notation as representing only **conventional tuning** (a chain of 700¢ fifths). Because the apotome becomes exactly 100¢, the sagittals fall at convenient, familiar-feeling sizes. This is also called **Trojan** notation.

{% page-ref page="12-relative-trojan.md" %}

## A word on precision

Several of these notations can be made as precise as you need. Sagittal offers a ladder of nested **symbol sets** — Spartan, Athenian, Promethean, Herculean, Olympian, Magrathean — each adding finer distinctions than the last. A low-precision notation uses only a handful of symbols; a high-precision one can pin down pitches to a fraction of a cent.

You do not need to worry about this yet. Start with the smallest set that does the job, and reach for a larger one only when your music actually requires the extra resolution. Knowing when you can *drop* an unnecessary symbol matters just as much as knowing when to add one.

{% page-ref page="../concept-explanations/symbol-sets.md" %}

That's all you need to get oriented. Head to whichever guide fits your tuning.
