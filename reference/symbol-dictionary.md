# Symbol Dictionary

Generated reference layer: one filterable master table plus per-symbol-set index pages, each entry giving the glyph, Unicode/SMuFL id, sagitype, Sagispeak, primary comma (directed name and ratio), cents, apotome complement, and symbol-set memberships. Shows both directed (prose) and undirected (frozen SMuFL) comma names. To be produced from `sheet/01-characters.csv`, `sheet/02-symbols-valid.csv`, and `sheet/03-primary-commas.csv`.
