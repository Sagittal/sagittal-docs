# Sagispeak Key

_This page is generated from the Sagittal data set; corrections belong in the data, not here._

[Sagispeak](../concept-explanations/sagispeak.md) is the spelling-and-pronunciation scheme for Sagittal symbols. A name is built from **consonants** (the flags) plus an ending **vowel** (the direction); **accents** add their own syllables. Everything from `sheet/06-sagispeak-key.csv` is below — full names in both directions, every alternate pronunciation, flag composition, and both sagitype forms.

## The rules in brief

- **Vowel = direction.** Up ends in **"ai"** (/aɪ/), down in **"ao"** (/aʊ/).
- **Consonant = flag.** Each flag type has one consonant letter, usually resembling the downward flag.
- **A name is stem + vowel.** The consonants of the flags, in the order they appear on the symbol, then the direction vowel: `p` + `ai` = **pai**, `pak` + `ao` = **pakao**. The IPA works the same way — take the stem's pronunciation below and append /aɪ/ or /aʊ/.
- **"a" = the shaft.** A lone "a" separating the left-side from the right-side consonants stands for the shaft.
- **Doubled flag → consonant + "h"** ("pp" → "ph" = /f/, "ss" → "sh", "kk" → "kh").

See [Sagispeak](../concept-explanations/sagispeak.md) for the worked explanation.
