# Per-EDO Notations

_This page is generated from the Sagittal data set; corrections belong in the data, not here._

Notational parameters for every equal division of the octave from 1 to 311, from `sheet/09-standard-edo-notations.csv`. For each EDO: its best-fifth size, and how many EDO-steps make up an **apotome** (chromatic semitone), a **limma** (diatonic semitone) and a **whole tone**. These are what you chain to lay down conventional notation before filling the gaps with sagittals — see [EDO Notations](../notation-how-to-guides/equal-divisions-of-the-octave.md).

A **negative apotome** marks the Mavila / bad-fifth EDOs (9, 16, 23, …): there the sharp would *lower* pitch, so Sagittal drops sharps and flats entirely and notates with limma-fraction sagittals instead. A **subset** EDO is notated inside a larger EDO’s scheme.

The per-EDO **accidental sequence** (which sagittals notate steps 1, 2, 3 … of each EDO) is **not** in this sheet — those columns are empty — so it is omitted below and deferred to the per-EDO pages generated from `@sagittal/system`.
